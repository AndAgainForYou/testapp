# Новий запис — вибір слота (Flutter)

Тестове завдання: екран для майстра б’юті-сфери — вибір послуги, дати та вільного часу з урахуванням робочих годин, обіду, буфера між записами та поточного часу.

## Вимоги

- **Flutter 3.38+** / **Dart 3.10+** — саме це вказано в ТЗ. У `pubspec.yaml` зараз `sdk: '>=3.9.2 <4.0.0'`, щоб проєкт відкривався й на трохи старішому Flutter; для перевірки виконання вимог ТЗ зіберіть на свіжому SDK (`flutter upgrade`).
- Дані завантажуються з **`assets/booking_schedule.json`** один раз при відкритті екрана (фікстура **як у ТЗ**, зокрема дати записів **2026-04-28 … 2026-04-30**).

Записи з JSON показуються лише для обраної дати, яка **збігається** з полем `date`. Екран пропонує **7 календарних днів від сьогодні** (`DateTime.now()`); щоб побачити зайнятість із фікстури на практиці, оберіть у чіпах дату з цього діапазону або тимчасово змініть системну дату / поля `date` у JSON під свою перевірку.

## Ключові рішення

1. **Керування станом — `ChangeNotifier` (`BookingController`)**  
   Достатньо для одного екрана без залежностей; при зміні **послуги** або **дати** викликається `notifyListeners()`, сітка береться з геттера `slots` і перераховується одразу.

2. **Генерація сітки — `SlotGenerator.buildGrid`**  
   - Крок **15 хв**; у сітку потрапляють лише старти з `start + duration ≤ кінець робочого дня` (тому «хвости», що не вміщаються до закриття, зникають — кейс 90 хв при обмеженому кінці дня).  
   - **Обід** і **записи з буфером ±15 хв** перевіряються перетином напівінтервалів `[start, end)` у хвилинах від півночі.  
   - **Сьогодні**: слот недоступний, якщо момент початку слота **не пізніший за** `DateTime.now()` (наприклад, о **13:47** слот **13:30** недоступний).  
   - Після зміни послуги з короткої на довгу ті самі старти можуть стати **disabled** — це лише перерахунок тієї ж сітки з іншою тривалістю.

3. **Підтвердження**  
   У консоль (`debugPrint`) і в **SnackBar** виводиться JSON: `serviceId`, `date`, `startTime`, `endTime`.

4. **Недоступні слоти**  
   `FilterChip` з `onSelected: null`; причина в **`Tooltip`** з `TooltipTriggerMode.tap`, щоб на тачскріні можна було швидко подивитись підказку.

## Структура коду

- `lib/booking/models.dart` — моделі та парсинг JSON.  
- `lib/booking/slot_generator.dart` — алгоритм сітки слотів.  
- `lib/booking/booking_controller.dart` — завантаження asset, вибір послуги/дати/слота.  
- `lib/booking/new_booking_screen.dart` — UI «Новий запис».  
- `test/slot_generator_test.dart` — unit-тести алгоритму (**7** сценаріїв).  
- `test/booking_fixture_test.dart` — парсинг фікстури з assets.

## Що б доробив з більшим часом

- Параметр «опорної дати» для демо без зміни системного часу.  
- Віджет-тести на зміну послуги/дати та golden-тести сітки.  
- Семантика / доступність для скрінрідерів.  
- Локалізація через ARB, якщо з’явиться друга мова.
